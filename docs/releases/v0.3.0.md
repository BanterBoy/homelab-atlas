# v0.3.0

Automatic layout is useful until a few small devices belong together or the composition needs a small adjustment. This release adds **Arrange** mode so device cards can move and resize without giving up the automatic starting point.

Drag a device card or its corner grip, use the arrow keys, or enter exact coordinates and sizes in the inspector. Cards snap to the grid and nearby cards, with alignment guides for card-to-card snaps. Hold Alt while dragging to bypass snapping. Content sets the minimum card size, so labels and services are not clipped. **Auto layout** returns every device card to automatic placement and can be undone.

Manual positions and sizes are kept in editable project saves and in SVG and PNG exports. Network and VLAN cards remain automatic, and connections remain logical relationships rather than freeform connectors.

Atlas 0.3 saves schema-version-2 projects. Schema-version-1 files open and upgrade automatically, but schema-version-2 files require Atlas 0.3 or newer. Keep a schema-version-1 JSON backup if you plan to downgrade.

Install v0.3.0:

```sh
curl -fsSLO https://github.com/aiden0rchad/homelab-atlas/releases/download/v0.3.0/compose.release.yaml
docker compose -f compose.release.yaml up -d
```

To update an existing released-image install, save a JSON project, set `ATLAS_VERSION=0.3.0` in the `.env` beside the Compose file, then run:

```sh
docker compose -f compose.release.yaml pull
docker compose -f compose.release.yaml up -d
```

Keep using the same browser address, including hostname, port, and protocol, so the same autosaved browser data appears.
