# Homelab Atlas v0.10.0

Released 2026-10-28.

Discovery's previous all-at-once form is now a guided Choose, Find, and Review flow.

## Highlights

- Each method has its own readiness and setup help. A failed check stays with that method and offers **Check again**.
- Network discovery starts with a useful Homelab app ports preset. Optional scan settings stay collapsed until needed.
- Review starts with every finding unchecked. **Select all shown** affects the current filtered page, while **Clear selection** clears every selection for the current device. Per-device drafts remain while moving between discovered devices.
- **Add to diagram** keeps the existing layout protection and creates one Undo step for the current device.
- The repository consolidates source under `app/`, `deploy/`, and `tools/`. The source ZIP uses the `app/` and `deploy/` layout and intentionally omits development tools.

## Compatibility

- Saved projects continue to use schema version 6.
- The published GHCR image remains scanner-free. Live Nmap scanning still requires the opt-in source build.
- Existing Docker collectors, Nmap XML imports, projects, layouts, and discovery bindings remain compatible.
- No LLM service or new runtime dependency is required.
