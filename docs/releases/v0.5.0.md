# v0.5.0

Atlas now uses visual logo pickers for device icons, network marks, new services, and existing service logos. Click an existing service logo to replace it without changing the service record.

Upload PNG, JPG, WebP, or SVG files up to 2 MB. The picker shows a preview and lets you choose a transparent, light, or dark background. Uploaded logos can be reused throughout the project. SVG uploads are converted to PNG, and stored images are at most 512px.

Uploaded assets are stored in project JSON and remain available offline. Self-contained SVG and PNG exports include them.

Atlas 0.5 saves schema-version-4 projects. Schema versions 1 through 3 import automatically after validation. Existing manual layouts and schema-version-3 network logo choices are preserved. Schema-version-4 files require Atlas 0.5 or newer, so save a pre-upgrade backup if you may downgrade.

Install v0.5.0:

```sh
curl -fsSLO https://github.com/aiden0rchad/homelab-atlas/releases/download/v0.5.0/compose.release.yaml
docker compose -f compose.release.yaml up -d
```

To update a released-image install, save a JSON project, set `ATLAS_VERSION=0.5.0` in the `.env` beside the Compose file, then pull and recreate the container.
