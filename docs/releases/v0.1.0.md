# v0.1.0 · First public release

Homelab Atlas v0.1.0 is the first public release of the local-first visual editor for clear, portable homelab diagrams. It combines devices, hardware facts, grouped services, network nodes, VLAN chips, and named logical relationships in an automatic layout. Three diagram themes, one to four columns, density controls, local logo search, and SVG/PNG export make the result useful in documentation without requiring a drawing tool.

This is an early release. Inventory is entered manually: Homelab Atlas does not discover hosts, monitor services, or inspect a live network. Projects autosave only in the current browser profile and origin. Use **Save project** to keep an editable JSON backup before updates or origin changes.

## Install

Requires Docker Engine or Docker Desktop with Compose v2:

```sh
curl -fsSLO https://github.com/aiden0rchad/homelab-atlas/releases/download/v0.1.0/compose.release.yaml
docker compose -f compose.release.yaml up -d
```

Open `http://localhost:8080`. The Compose file uses the versioned `0.1.0` GHCR image and binds to loopback by default.
