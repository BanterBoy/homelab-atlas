# v0.1.0 · First public release

I started Homelab Atlas after I posted my homelab diagram on Reddit and someone asked how they could make one too. I wanted a simple app for adding machines and apps, getting the logos in, and updating the diagram later without depending on an LLM. v0.1.0 is the first public release.

You add devices, hardware notes, grouped services, network nodes, VLAN chips, and connections. Atlas handles the layout, with three themes, one to four columns, two spacing options, a searchable local logo catalog, and SVG or PNG export.

This is still an early release. You enter the inventory yourself. Atlas does not discover hosts, monitor services, or inspect your network. Autosave only exists in the current browser profile at the hostname, port, and protocol you used. Use **Save project** to keep an editable JSON backup before updates or address changes.

## Install

Requires Docker Engine or Docker Desktop with Compose v2:

```sh
curl -fsSLO https://github.com/aiden0rchad/homelab-atlas/releases/download/v0.1.0/compose.release.yaml
docker compose -f compose.release.yaml up -d
```

Open `http://localhost:8080`. The Compose file uses the `0.1.0` image and, by default, only listens on the machine running Docker.

## Downloads

- `homelab-atlas-0.1.0.zip`: app files for Python 3.10+ and a current browser
- `compose.release.yaml`: Docker Compose file for the published GHCR image
- `SHA256SUMS`: checksums for both downloadable files
- `ghcr.io/aiden0rchad/homelab-atlas:0.1.0`: Linux AMD64 and ARM64 container image

GitHub also creates source archives automatically. Use the portable ZIP if you want the prepared files for running the app without Docker.

The [installation and update guide](https://aiden0rchad.github.io/homelab-atlas/getting-started) covers the other ways to run Atlas. Read the [backup and sharing guide](https://aiden0rchad.github.io/homelab-atlas/sharing) before moving a project, and check the [privacy page](https://aiden0rchad.github.io/homelab-atlas/privacy) before putting Atlas on your network or sharing a diagram. Docker image details are on the [GHCR package page](https://github.com/users/aiden0rchad/packages/container/package/homelab-atlas).
