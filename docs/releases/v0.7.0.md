# v0.7.0

Atlas now previews privacy-filtered SVG and PNG exports before download. The **Hide network details** switch is on by default and replaces valid IP addresses, MAC addresses, URLs, and emails with `[hidden]`; you can also add up to 30 case-insensitive literal terms. Filtering preserves the original layout and does not modify the saved project, autosave, backups, or undo history.

The preview is a review aid, not complete anonymization. Custom names need explicit terms, text baked into uploaded images is unchanged, and saved JSON retains every project detail. Read the [export guide](https://aiden0rchad.github.io/homelab-atlas/exporting) and [privacy notes](https://aiden0rchad.github.io/homelab-atlas/privacy) before sharing.

Docker discovery can now connect to a Hawser Standard-mode HTTPS agent using `X-Hawser-Token`. Portainer API-key support remains available, but the two credential types cannot be configured together. Hawser Edge/outbound WebSocket mode is not supported.

Atlas 0.7.0 keeps project schema version 5. Existing projects, uploaded logos, discovery bindings, and manual layouts do not need migration.

Install v0.7.0:

```sh
curl -fsSLO https://github.com/aiden0rchad/homelab-atlas/releases/download/v0.7.0/compose.release.yaml
docker compose -f compose.release.yaml up -d
```

Read [Docker discovery](https://aiden0rchad.github.io/homelab-atlas/discovery) before configuring a remote Docker or Hawser endpoint.
