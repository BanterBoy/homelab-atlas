# v0.7.0

Atlas now previews privacy-filtered SVG and PNG exports. Network details are hidden by default: valid IP addresses, MAC addresses, URLs, and emails become `[hidden]`. You can add up to 30 case-insensitive literal terms for private hostnames, domains, or other names. Filtering preserves the original canvas size, card geometry, project, autosave, backups, and undo history.

The filter is a review aid, not complete anonymization. Custom names need explicit terms, text baked into uploaded logos is unchanged, and saved JSON keeps every project detail. Read the [export guide](https://aiden0rchad.github.io/homelab-atlas/exporting) and [privacy notes](https://aiden0rchad.github.io/homelab-atlas/privacy) before sharing.

The restricted Docker collector can now read inventory through a Hawser Standard-mode HTTPS agent using `X-Hawser-Token`. Atlas still calls only Docker `GET /version` and the negotiated `GET /v…/containers/json?all=1` endpoint. Portainer API-key support remains available, but the two credential types cannot be configured together. Hawser Edge/outbound WebSocket mode is not supported. The protocol was tested with an HTTP/HTTPS fixture at the pinned upstream contract, not a live user agent.

Atlas 0.7.0 keeps project schema version 5. Existing projects, uploaded logos, discovery bindings, and manual layouts do not need migration.

Install v0.7.0:

```sh
curl -fsSLO https://github.com/aiden0rchad/homelab-atlas/releases/download/v0.7.0/compose.release.yaml
docker compose -f compose.release.yaml up -d
```

Read [Docker discovery](https://aiden0rchad.github.io/homelab-atlas/discovery) before configuring a remote Docker or Hawser endpoint.
