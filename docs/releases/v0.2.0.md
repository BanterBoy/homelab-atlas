# v0.2.0

The first diagram and editor worked, but parts of them still felt rough. This release makes the poster easier to read and the editor calmer to use.

Diagram text is lighter, hardware facts have a clearer hierarchy, and explicit `Label: value` rows stay aligned. Recognized Intel and AMD CPU names can use a small readable badge. Small service groups now take less space, while dense groups keep their labels clear.

The editor has quieter controls, inventory search, a focused canvas view, and a mobile inventory drawer. **Export** now opens the SVG and PNG choices together. **Save** still downloads the editable JSON project. Existing schema-version 1 project files still open.

Install v0.2.0:

```sh
curl -fsSLO https://github.com/aiden0rchad/homelab-atlas/releases/download/v0.2.0/compose.release.yaml
docker compose -f compose.release.yaml up -d
```

To update an existing released-image install, set `ATLAS_VERSION=0.2.0` in the `.env` beside the Compose file, then run:

```sh
docker compose -f compose.release.yaml pull
docker compose -f compose.release.yaml up -d
```

Save a JSON project first. Keep using the same browser address, including hostname, port, and protocol, so the same autosaved browser data appears.
