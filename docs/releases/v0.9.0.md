# Homelab Atlas v0.9.0

Released 2026-10-28.

This release adds explicit bounded Nmap TCP scans. Install Nmap on the Atlas server, enter IPv4 targets in the configured ranges, and choose **Scan network**. Blank ports use the common 100 TCP ports; custom ports and fixed lightweight service identification are optional. Stop cancels the process. Firewalls can still hide hosts.

Live results use the same multi-host review as XML import. Every row starts unchecked, nothing changes until **Apply selected**, and each Apply remains undoable without moving manually arranged cards. XML import still works without Nmap and continues to support IPv6 results.

The published GHCR image remains scanner-free. Source users can opt into Alpine's `nmap`, `nmap-nselibs`, and `nmap-scripts` packages with `ATLAS_WITH_NMAP=true docker compose up -d --build`; the release source ZIP includes `compose.nmap.yaml` for an opt-in local build. Nmap remains independently licensed under the NPSL.
