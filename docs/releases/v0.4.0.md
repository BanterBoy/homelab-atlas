# v0.4.0

Network nodes can now show an explicit provider logo and an optional second mark for a backup provider. Select a network node, choose **Logo**, then search by provider, `ISP`, region, country, or brand alias. Choose **Secondary logo** when two providers share the same node.

This release includes 27 locally bundled marks for major US and European providers. The selected marks stay available offline and are embedded in SVG and PNG exports.

Atlas 0.4 saves schema-version-3 projects. Schema-version-1 and schema-version-2 files import automatically, and existing schema-version-2 manual layouts remain unchanged. Schema-version-3 files require Atlas 0.4 or newer. Save a pre-upgrade JSON backup if you may downgrade.

Install v0.4.0:

```sh
curl -fsSLO https://github.com/aiden0rchad/homelab-atlas/releases/download/v0.4.0/compose.release.yaml
docker compose -f compose.release.yaml up -d
```

To update an existing released-image install, save a JSON project, set `ATLAS_VERSION=0.4.0` in the `.env` beside the Compose file, then run:

```sh
docker compose -f compose.release.yaml pull
docker compose -f compose.release.yaml up -d
```

Keep using the same browser address, including hostname, port, and protocol, so the same autosaved browser data appears.
