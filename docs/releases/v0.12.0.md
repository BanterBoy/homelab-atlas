# Homelab Atlas v0.12.0

Released 2026-10-28.

Discovery setup now shows one focused instruction at a time. Docker guidance separates local Compose, native or remote collectors, and a one-time snapshot path. Nmap guidance separates source-built Compose from native installs. Already configured Docker servers keep the direct server picker.

Scan actions stay disabled until required input is present. Readiness, collector, and access-token failures keep their useful context and offer specific retry guidance without starting a scan.

Every finding still starts unchecked. **Add selected to diagram** remains an explicit, undoable action; existing cards stay in place, and additions that would overlap another card are blocked.

Verification includes the automated app, discovery, packaging, and documentation checks, plus browser checks of configured and fresh setup paths, imports, review, cancellation, Undo, and mobile layout.
