# Homelab Atlas v0.11.1

Released 2026-10-28.

This patch fixes **Focus canvas** on tablet-sized screens. The canvas now expands to the full workspace width even when the inspector was open.

Diagram and export output, schema version 6 projects, saved layouts, collectors, and discovery behavior are unchanged. No dependency was added.
