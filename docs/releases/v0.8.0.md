# Homelab Atlas v0.8.0

Released October 27, 2026.

## Nmap XML import

**Discover devices** now accepts a user-supplied Nmap XML file. Atlas does not run Nmap or probe a network. It normalizes explicitly up hosts and open TCP/UDP endpoints into the existing unchecked review, including ping-only hosts, IPv6, hostnames, vendor text, and canonical MAC addresses.

A network name namespaces stable identities. Reuse it for later scans. MAC identity survives an IP change; files, scan times, product versions, and XML ordering do not define identity. Multi-host files stay open so each host can be reviewed and applied separately.

## Safe merging

Host rows can add an empty **Network host** card or link to an existing card. Endpoint rows add or link services. Existing device metadata, services, connections, positions, and widths are not rewritten. New cards go below existing cards; growth that would overlap another card is blocked. Each Apply is one undo step.

Schema version 6 adds device-level host bindings. Valid schema versions 1 through 5 migrate while preserving existing data and manual layout.

## Privacy and limits

The selected XML reaches only the user's Atlas backend transiently. Script output, credentials, command arguments, traces, fingerprints, and unknown fields are discarded from normalized review. Imports are limited to 2 MB, 256 host records, 1,000 findings, and 64 nesting levels. Applied IP facts remain in JSON but can be hidden in SVG/PNG with the existing privacy filter.
