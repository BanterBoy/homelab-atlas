# Homelab Atlas v0.11.0

Released 2026-10-28.

The editor now uses a calmer workspace with separate inventory, canvas, and inspector areas. Diagram and export output are unchanged.

## Highlights

- Project actions now live in a **File** menu, with Undo, Redo, and Export kept in the top bar.
- Device editing is split into **Details**, **Apps**, and **Layout** tabs.
- App rows, logo choices, discovery, connections, and export dialogs have clearer spacing and controls.
- Arrange, Auto layout, Diagram settings, zoom, fit, and focus controls are grouped around the canvas.
- Mobile layouts keep essential controls available and make long inventory and dialog content easier to reach.

## Compatibility

- Saved projects continue to use schema version 6.
- Existing projects, manual layouts, Docker collectors, discovery bindings, Nmap XML imports, and privacy filters remain compatible.
- Diagram SVG and PNG output is unchanged.
- The published GHCR image remains scanner-free. Live Nmap scanning still requires the opt-in source build.
- No new runtime dependency is required.
