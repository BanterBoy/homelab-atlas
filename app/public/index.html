This lists containers on that Docker host, not every computer on your network.

Connect your Docker host

Atlas uses a separate restricted collector to list containers from one Docker daemon.

  1. Generate a token. openssl rand -hex 32
  2. Create or open .env in the Atlas Compose folder on your Docker host, then add: ATLAS_COLLECTOR_TOKEN=paste-your-generated-value
  3. Start the collector for your setup.
Commands for each Compose setup

Source checkout:

docker compose --profile discovery up -d

Released Compose file:

docker compose -f compose.release.yaml --profile discovery up -d

Enable network scanning

The published image is scanner-free. From a source checkout or extracted ZIP, save ATLAS_WITH_NMAP=true in .env, then rebuild:

ATLAS_WITH_NMAP=true docker compose up -d --build
